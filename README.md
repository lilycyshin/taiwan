# 챔댕슝슝 🩷

우리 둘 가오슝(高雄) 신혼여행 모바일 웹앱. 2026.10.8 – 10.11

## 기능
- **일정**: 일자별 타임라인 + 동선 지도 + 실시간 길찾기(Google Maps 대중교통). "지금 여기서 / 이전 장소부터" 길안내, 택시 기사님용 중국어 카드.
- **기록**: 일정마다 메모·사진 첨부, 일자별 앨범. 사진은 기기에 저장(오프라인), 백업/복원 가능.
- **회화**: 상황별 기초 중국어 + 발음 + TTS 읽어주기, 숫자표.
- **환율**: NT$ ↔ 원 계산기 (실시간 환율, 오프라인 대비 기본값 포함).

## 홈 화면에 설치 (PWA)
1. 아이폰 Safari / 안드로이드 Chrome에서 배포 주소 열기
2. 공유 → "홈 화면에 추가"
> 설치/오프라인은 HTTPS에서만 동작해요. GitHub Pages로 배포하면 됩니다.

## 배포
Settings → Pages → Branch: `main` / root 선택 → 저장.
몇 분 뒤 `https://lilycyshin.github.io/taiwan/` 에서 열려요.

`data.js`를 고치거나, 앱에서 직접 일정 추가·수정·삭제 가능(기기에 저장됨).

## Supabase 클라우드 백업
프로젝트 `dcrqvfzlxjvoiwklavsq`를 연결했습니다. 사진은 기기에 먼저 저장되고, 기록 탭에서 로그인 후 **백업**을 눌러 사진·메모·일정을 비공개 Storage에 저장합니다. **복원**은 같은 계정의 백업을 다른 기기로 불러옵니다. 실시간 공동 앨범은 아직 지원하지 않습니다. 백업 한 파일은 최대 50MB입니다.

1. Supabase SQL Editor에서 `supabase-setup.sql`을 한 번 실행합니다. 비공개 `trip-backups` 버킷과 사용자별 접근 정책을 만듭니다.
2. Authentication → Email Templates → Magic Link에 인증번호 `{{ .Token }}`이 보이도록 설정합니다. 이메일 인증을 활성화해야 합니다.
3. 기록 탭에서 이메일과 인증번호로 로그인하고 백업·복원을 사용합니다.

브라우저에는 publishable 키만 사용합니다. 프로젝트 관리자 키는 앱에 넣지 않습니다. 두 사람이 각자 로그인한 계정의 백업은 분리됩니다.
